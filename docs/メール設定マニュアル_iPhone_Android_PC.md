# メール設定マニュアル（iPhone / Android / パソコン）

**株式会社ヴィレッジ　御中**
**対象メール：`@village2024.jp`（CoreServer）／ 作成 2026-07-07・改訂 2026-07-31**

本書は、会社のメールを各端末で送受信するための設定手順書です。
①の設定情報をご用意のうえ、②〜④のうち該当する端末の手順をご覧ください。

---

## ① 設定情報（最初にご確認ください）

| 項目 | 入力する値 |
|------|-----------|
| メールアドレス | `info@village2024.jp` |
| パスワード | メールのパスワード（別紙「メール設定一覧」に記載） |
| サーバー名 | `v2008.coreserver.jp`（受信・送信とも同じ） |
| ユーザー名 | `info@village2024.jp`（メールアドレスをそのまま入力） |
| メールの種類 | IMAP（アイマップ） |

> ※サーバー名は `v2008.coreserver.jp` です。独自ドメイン `village2024.jp` ではありません。誤入力の多い項目のため、ご注意ください。
> ※IMAP は、サーバー上でメールを管理する方式です。複数の端末で同じ受信トレイを共有でき、機種変更後も過去のメールを参照できます。

### ポート番号・暗号化（CoreServer 標準値・変更不要）

| | ポート番号 | 暗号化 | 認証（ログイン） |
|---|---|---|---|
| **受信** | **993** | SSL/TLS＝オン | あり |
| **送信** | **465** | SSL/TLS＝オン | あり（受信と同じID・パスワード） |

> ※接続できない場合の代替値：受信 **143**／送信 **587**（暗号化は **STARTTLS** を選択）。
> なお `143` と `SSL/TLS` の組み合わせでは接続できません。

## ② iPhone・iPad の設定

iPhone に標準搭載の「メール」アプリを使用します。

1. 「設定」（歯車のアイコン）を開きます。
2. 「アプリ」→「メール」を選択します。（iOS のバージョンにより「メール」が直下にある場合があります）
3. 「メールアカウント」→「アカウントを追加」を選択します。
4. 「その他」→「メールアカウントを追加」を選択します。
5. 名前（例：ヴィレッジ）・メール・パスワード・説明（例：会社メール）を入力し「次へ」。
6. 画面上部のタブが「**IMAP**」になっていることを確認します。
7. 「受信メールサーバ」「送信メールサーバ」の**両方**に、①のサーバー名・ユーザ名・パスワードを入力します。
8. 右上の「次へ」→「保存」を選択します。確認処理に時間を要する場合があります。

> ※送信側が「オプション」と表示されていても、ユーザ名とパスワードは**必ず**入力してください。未入力の場合、受信はできても送信ができません。
> ※「サーバの識別情報を検証できません」と表示された場合は「続ける」を選択してください。

## ③ Android の設定

機種による差異が少ない「Gmail」アプリを使用します。（Gmail のアドレスをお持ちでない場合も設定できます）

1. 「Gmail」アプリを開きます。
2. 右上のアカウントアイコン →「別のアカウントを追加」を選択します。
3. 「その他」を選択し、メールアドレスを入力して「次へ」。
4. 「個人用（IMAP）」を選択し、パスワードを入力して「次へ」。
5. 「受信サーバーの設定」に①のユーザー名・パスワード・サーバー名を入力し、**ポート993／SSL** を選択して「次へ」。
6. 「送信サーバーの設定」で「**ログインが必要**」をオンにし、同じ値を入力、**ポート465／SSL** を選択して「次へ」。
7. 同期頻度などの確認画面は、そのまま「次へ」。
8. 名前（例：ヴィレッジ）を入力し「次へ」を選択します。

> ※機種により「個人用（IMAP）」が「IMAP」と表示される場合があります。同一の設定です。

## ④ パソコン（Windows）の設定

無料のメールソフト「Thunderbird（サンダーバード）」を使用する手順です。
Outlook をご利用の場合は、下段の「Outlook の場合」をご覧ください。

### Thunderbird のインストール（未導入の場合）

1. Edge などのブラウザで「Thunderbird ダウンロード」と検索します。
2. 公式サイト（thunderbird.net）から「無料ダウンロード」を選択します。
3. ダウンロードしたファイルを開き、画面の案内に従って進めます。

### アカウントの追加

1. Thunderbird を起動します。
2. 「新しいアカウントを作成」→「メール」を選択します。
3. 名前（例：ヴィレッジ）・メールアドレス・パスワードを入力し「続ける」。
4. 自動設定では正しく検出されないため「**手動設定**」を開き、下表のとおり入力します。
5. 「再テスト」→「完了」を選択します。受信トレイが表示されれば設定完了です。

| 項目 | 受信サーバー | 送信サーバー |
|------|-------------|-------------|
| 方式 | IMAP | SMTP |
| サーバー名 | `v2008.coreserver.jp` | `v2008.coreserver.jp`（受信と同じ） |
| ポート | **993** | **465** |
| 接続の保護 | SSL/TLS | SSL/TLS |
| 認証方式 | 通常のパスワード認証 | 通常のパスワード認証 |
| ユーザー名 | `info@village2024.jp` | `info@village2024.jp` |

> ※2台目以降のパソコンも同じ手順です。IMAP のため、受信トレイは全端末で共有されます。

### Outlook の場合

1. 「ファイル」→「アカウントの追加」を選択します。
2. メールアドレスを入力し、「詳細オプション」→「自分で自分のアカウントを手動で設定」にチェックして「接続」。
3. 種類は「**IMAP**」を選択します。
4. 受信・送信ともサーバー `v2008.coreserver.jp`／受信993・送信465／暗号化 SSL/TLS を入力します。
5. パスワードを入力し「接続」を選択します。受信トレイが表示されれば設定完了です。

## ⑤ 送受信テスト

設定後、受信・送信の両方をご確認ください。

1. **受信**：他のメールアドレス（個人の Gmail など）から会社アドレス宛に送信し、受信を確認します。
2. **送信**：会社アドレスから他のメールアドレス宛に送信し、到着を確認します。

> ※両方が確認できれば設定完了です。いずれかに失敗する場合は⑥をご確認ください。

## ⑥ トラブル対応

| 症状・ご質問 | 確認する項目 |
|-----------|----------------|
| 受信はできるが、送信できない | 送信の「認証（ログインが必要）」がオフになっていないか確認。または送信ポートを 465 ⇔ 587 で切替。 |
| 送信はできるが、受信できない | 受信のサーバー名・ポート993・暗号化（オン）・パスワードを再確認。 |
| 「接続できません」と表示される | サーバー名の誤入力が主な原因です。`v2008.coreserver.jp` で相違ないか確認。 |
| ポート143 で接続できない | 143 の場合は暗号化を STARTTLS に変更。推奨は 993＋SSL/TLS。 |
| パスワードが不明 | CoreServer の管理画面で再設定できます。 |
| 複数端末で同じメールを参照したい | 本書のとおり IMAP で設定すれば、受信トレイは共有されます。 |
| 機種変更でメールは消えるか | 消えません。新しい端末で同じ設定を行えば、過去のメールも参照できます。 |
